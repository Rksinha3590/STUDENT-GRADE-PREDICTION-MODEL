THIS IS STUDENT GRADE PREDICTION MODEL PROJECT...WHERE USER CAN FIND THE PREDICTION OF THEIR FINAL YEAR GRADES..

Its work on Linear Regression....

software use to run this application:- Xampp Mysql, Flask. and install all other dependencies as per requirements..

how to run:- firstly export the bcsp db file to mysql then activate virtual environment venv to activate all  requirements and dependencies    of  the PROJECT...and run the main.py file in the terminal and then open the [localhost:5000](http://127.0.0.1:5000/) in the browser and then you can see the application running..

step1:- install Xampp 

step2:- Run Apache Server and Run MYSQL

step3:- open MYSQL ADMIN PAGE PhpMyAdmin http://localhost/phpmyadmin/

step3:- export bcsp.sql file in PhpMyAdmin..it will create a database named bcsp

step4:- open project in vs code

step6:- activate virtual environment by following cmd: venv/Scripts/activate

step7:- after activating venv run the application by using coderunner extension.. or by following cmd: python main.py runserver

step8:- success...you can see the application is running..on http://127.0.0.1:5000/ this localhost...you can manually type this url in browser

step9:- to close the application.. use CTRL+C in terminal..it will quit the localhost...
